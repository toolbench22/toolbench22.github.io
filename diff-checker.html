Text Diff Checker

Compare two blocks of text and see added and removed lines highlighted, with a change count. Longest-common-subsequence diff, computed locally.

How to use the Diff Checker

  1. Paste the original text on the left and the changed text on the right.
  2. Press Compare. Lines are aligned and marked: green added, red removed, plain unchanged.
  3. Read the +N / -M counter above the result for a quick scope check before you review the details.

Frequently asked questions

How does the comparison work?

It computes the longest common subsequence of lines and walks it, so the output is a minimal edit script rather than a naive positional comparison.

Can it compare word by word?

This version works at line level, which is what you want for code, config files and articles. For word-level diffs, split your text so each word or sentence is on its own line.

Is there a size limit?

Above roughly 2000 lines per side the tool switches to a fast fallback listing everything as removed then added, to keep the tab responsive.
