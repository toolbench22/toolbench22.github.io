Base32 Encoder & Decoder

Encode text to Base32 or decode Base32 back to text using RFC 4648. Optional padding removal, full UTF-8 support, nothing leaves your browser.

How to use the Base32 Encoder

  1. Type or paste your text on the left and press Encode to get Base32.
  2. To decode, paste the Base32 string and press Decode. Padding characters (=) and spaces are ignored.
  3. Tick "No padding" when the output feeds a system that rejects trailing equals signs.

Frequently asked questions

Where is Base32 used instead of Base64?

Base32 only uses A-Z and 2-7, so it survives case-insensitive systems, hand transcription and human error. TOTP secrets and some DNS records use it; Base64 is more compact but case-sensitive.

Is Base32 encryption?

No. It is a reversible encoding with no key, so anyone can decode it instantly. Never use it to protect a password or token.

Why do I get an error when decoding?

Base32 only allows A-Z and 2-7 after removing padding. Any other character (including 0, 1, 8, 9) is invalid and the decoder reports which one it hit.
