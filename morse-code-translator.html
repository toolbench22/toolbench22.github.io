Morse Code Translator

Translate text into Morse code and decode Morse back to text. Letters, numbers and punctuation, with word breaks marked by a slash.

How to use the Morse Code Translator

  1. Type text in the left box and press "Text → Morse" to encode it.
  2. To decode, paste Morse into the left box and press "Morse → Text".
  3. Inside Morse, a single space separates letters and a slash ( / ) separates words.

Frequently asked questions

Which characters are supported?

A-Z, 0-9 and common punctuation (. , ? ! / ( ) & : ; = + - _ " $ @). Unsupported characters are dropped rather than producing broken output.

Is Morse case sensitive?

No. Input is uppercased before encoding, and decoding always returns uppercase letters.

What does SOS look like?

... --- ... — three dots, three dashes, three dots. It is sent as one word with no letter gaps wider than a single space.
