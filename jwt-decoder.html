JWT Decoder (Header, Payload, Claims)

Decode a JSON Web Token to see its header, payload and human-readable claims like issuer and expiry. Base64url decoding only, no verification.

How to use the JWT Decoder

  1. Paste the whole token, including the dots. A leading "Bearer " prefix is fine.
  2. Press Decode to see the header and payload as formatted JSON, plus claims such as issuer, subject and expiry in ISO time.
  3. Compare the expiry against your clock to see whether the token is stale.

Frequently asked questions

Does this verify the signature?

No. Verification requires the secret or public key, which must stay on your server. Never trust a token just because it decodes.

Is it safe to paste a real token here?

Decoding happens in your browser and nothing is transmitted, so the token does not leave the machine. That said, treat any live token as a credential: copy it as rarely as possible and rotate it if in doubt.

Why does ''alg: none'' matter?

A token claiming alg none has no signature. If a server accepts it, anyone can forge tokens, so always whitelist the algorithms you accept.
