JSON Formatter & Validator

Format, validate and minify JSON in your browser. Clear error messages with the exact position, sort keys, choose indentation. Nothing is uploaded.

How to use the JSON Formatter

  1. Paste or type your JSON into the left box — the result appears on the right as you type.
  2. Pick 2 spaces, 4 spaces or tabs, and tick "Sort keys A-Z" if you want deterministic output for diffs.
  3. If the JSON is invalid, the red message tells you exactly what the parser complained about. Fix the comma, quote or bracket it points at.
  4. Hit Copy when you are done. Everything runs locally, so secrets in your JSON never leave the machine.

Frequently asked questions

Is my JSON uploaded to a server?

No. Parsing and formatting happen with JavaScript inside your browser. You can turn off your network after the page loads and the tool still works.

Why does valid-looking JSON fail?

The most common causes are trailing commas, single quotes instead of double quotes, unquoted keys, comments (JSON does not allow them) and NaN/Infinity values.

How large a file can it handle?

A few megabytes is fine on a normal machine. Above that the browser tab may stutter, because formatting builds one huge string.
