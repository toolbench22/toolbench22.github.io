Regular Expression Tester

Test JavaScript regular expressions against sample text with live highlighting, match indexes and capture groups. Invalid patterns show the exact error.

How to use the Regex Tester

  1. Enter the pattern without slashes — for example \b\w+@\w+\.\w{2,}\b.
  2. Set flags: g for all matches, i for case-insensitive, m for multiline, s to let dot match newlines.
  3. Paste the test string. Matches are highlighted and listed with their character index and capture groups.

Frequently asked questions

Why does my pattern hang on some input?

Catastrophic backtracking from nested quantifiers such as (a+)+ against long non-matching text. This tester stops after 5000 matches, but your production code needs a safer pattern or a timeout.

Which regex flavour is this?

JavaScript, the RegExp engine in your browser. Lookbehind and named groups are supported in current engines; POSIX classes are not.

Do I need the g flag?

Without g you get only the first match. With g every match is found, which is what the highlighted list shows.
