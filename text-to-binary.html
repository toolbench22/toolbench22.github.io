Text to Binary Converter

Turn text into space-separated 8-bit binary bytes and back. UTF-8 based, so accents, Cyrillic and emoji work correctly.

How to use the Text to Binary

  1. Type or paste text, then press "Text to binary".
  2. To go back, paste bits (spaces and line breaks are ignored) and press "Binary to text".
  3. Each group of eight bits is one byte, which is one UTF-8 code unit.

Frequently asked questions

Why does one character become more than 8 bits?

UTF-8 uses one byte for ASCII and up to four bytes for other scripts and emoji. A Chinese character is three bytes, so 24 bits.

Is this the same as machine code?

It is the byte-level representation of text, not instructions. Real machine code also encodes an instruction set and operands.

Can I hide a message in binary?

You can, but it is trivially readable to anyone who knows the encoding. It is obfuscation, not encryption.
