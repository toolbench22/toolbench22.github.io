SHA Hash Generator (SHA-1, SHA-256, SHA-384, SHA-512)

Compute SHA-1, SHA-256, SHA-384 and SHA-512 hashes of any text using the Web Crypto API. All four digests at once, nothing uploaded.

How to use the Hash Generator

  1. Paste the text you want to hash.
  2. Press "Hash it (all algorithms)" to compute SHA-1, SHA-256, SHA-384 and SHA-512 in one pass.
  3. Copy the digest you need. Compare with the checksum published by the source to verify a download or a signed value.

Frequently asked questions

Can I decrypt a hash?

No. Hashing is one-way by design. The only attack is guessing inputs and hashing them, which is why slow, salted password hashes like bcrypt exist.

Is SHA-1 still safe?

For integrity checks against accidental corruption yes; for signatures and security decisions no. Use SHA-256 or better.

Why does Web Crypto fail on some pages?

crypto.subtle is only available in secure contexts — HTTPS or localhost. On plain HTTP the browser disables it.
