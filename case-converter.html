Text Case Converter

Convert text between UPPER, lower, Title, Sentence, camelCase, PascalCase, snake_case, kebab-case and CONSTANT_CASE in one click.

How to use the Case Converter

  1. Paste your text in the input box.
  2. Click the style you need — UPPER CASE, Title Case, camelCase, snake_case and the rest.
  3. Copy the result. Press another style button to convert the original again rather than the previous output.

Frequently asked questions

What is the difference between camelCase and PascalCase?

camelCase starts with a lowercase letter (myVariableName), PascalCase starts uppercase (MyVariableName). Both drop the spaces and capitalise each following word.

Which style should I use for URLs and files?

kebab-case for URLs and file names, snake_case for JSON keys and database columns, camelCase or PascalCase for code identifiers — follow whatever the project already uses.

Does it handle non-English text?

CJK characters are preserved as-is; the style conversions mainly affect Latin words, which is where they matter.
