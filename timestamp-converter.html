Unix Timestamp Converter

Convert Unix timestamps to readable dates and back. Seconds or milliseconds detected automatically, with ISO 8601, UTC and local output.

How to use the Timestamp Converter

  1. Paste an epoch number (10 digits = seconds, 13 digits = milliseconds) or a date string like 2024-05-01T12:30:00Z.
  2. Read the converted values instantly: Unix seconds, milliseconds, ISO 8601, UTC, your local time and a relative phrase.
  3. Press "Use current time" whenever you need the current epoch value for logs, tokens or database rows.

Frequently asked questions

Seconds or milliseconds?

Both are accepted. A 10-digit number is read as seconds, a 13-digit number as milliseconds, which matches JavaScript's Date and most Unix tooling.

Which timezone is shown?

ISO 8601 and UTC lines are absolute. The "local time" line uses your own device timezone, which is what you usually want when comparing against your logs.

Why is my server timestamp off by hours?

Usually the server stores UTC and you are reading it as local, or the value is in microseconds (16 digits) from a database like PostgreSQL. Divide by 1000 first.
