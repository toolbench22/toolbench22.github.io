Strong Password Generator

Generate strong random passwords with a live entropy readout. Choose length and character sets, exclude look-alike characters. Generated locally.

How to use the Password Generator

  1. Set the length. Sixteen characters or more is a good default; anything above 20 is comfortably strong.
  2. Choose the character sets you need. Mixing upper, lower, digits and symbols raises the entropy per character.
  3. Read the entropy number: below 60 bits is fair, 80 bits and above is very strong. Press Generate again for a new password.

Frequently asked questions

How is the entropy calculated?

Entropy = length x log2(pool size). It measures how many guesses an attacker needs on average, assuming the generator is truly random — which here it is, because it uses crypto.getRandomValues.

Should I reuse the same password?

No. Reuse is what turns one breached forum into ten compromised accounts. Use a password manager and one unique password per site.

Is the password ever transmitted?

No. It is created in your browser's memory. Close the tab and it is gone.
