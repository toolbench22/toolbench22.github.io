Why these tools are different

Most online utilities send your input to a server. That is fine for a URL slug and a terrible idea for a JWT, an API key or a draft you have not published. Everything on this site is plain JavaScript that runs on your own device: turn off your network after the page loads and the tools keep working.

What is inside

  • Developer tools — JSON formatter, Base64, URL encoder, timestamp converter, UUID generator, regex tester, hash generator, HTML entities, color converter.
  • Text tools — word counter, case converter, diff checker, line sorter, slug generator, Lorem Ipsum, Markdown preview.
  • Converters — units, number bases, text to binary.
  • Data and security — CSV to JSON, JWT decoder, password generator.

How to use them

Pick a tool, paste your value, copy the result. Nothing to install, no account, no rate limit. Bookmark the ones you use weekly — pressing Ctrl + D is faster than searching for them again.
