Unicode Character Inspector

Inspect any text character by character: code point, U+ hex value, decimal, UTF-8 byte length, HTML entity and character class.

How to use the Unicode Inspector

  1. Paste text into the box — every character is inspected as you type.
  2. Read each code point in U+ notation, its decimal value and how many UTF-8 bytes it occupies.
  3. Use the HTML entity column to embed the character in markup without encoding issues.

Frequently asked questions

Why do some characters take 4 bytes?

UTF-8 uses 1 byte for ASCII, 2-3 bytes for most other scripts and 4 bytes for supplementary plane characters such as emoji. The byte column shows the real storage cost.

What is a code point?

The number Unicode assigns to a character. U+0041 is A, U+4E2D is the Chinese character for middle. Code points are the stable identifier; the glyph is just how a font draws it.

Is my text uploaded?

No. Inspection runs in your browser; the text never leaves the page.
