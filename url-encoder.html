URL Encoder / Decoder

Percent-encode a value or decode a full URL, then read the query string as a clean parameter table. No requests, no logging.

How to use the URL Encoder

  1. Paste the value on the left and press Encode for percent encoding.
  2. Tick "Treat input as a full URL" when you want to keep : / ? & # intact while only escaping spaces and unsafe characters.
  3. Press Decode to reverse it, and the decoded query parameters show up underneath as a table.

Frequently asked questions

encodeURIComponent or encodeURI?

Use component style for a single query parameter value; use full-URL style when the whole address must stay readable. This tool gives you both with one checkbox.

Why does + become a space?

In application/x-www-form-urlencoded data a plus sign means a space. When decoding, this tool treats + as a space; when encoding it always emits %20, which is unambiguous.

Can it decode double-encoded URLs?

Press Decode twice. Double encoding is common when a URL was passed as a parameter inside another URL.
