HTML Entity Encoder / Decoder

Escape HTML special characters to entities and decode numeric or named entities back to text. Prevent broken markup and accidental tag injection.

How to use the HTML Entity Encoder

  1. Paste the text or HTML fragment on the left.
  2. Press Encode to turn & < > " ' into entities, or Decode to turn entities back into characters.
  3. Tick "Encode all non-ASCII" when the output must be pure ASCII for an old email system or a legacy template.

Frequently asked questions

Does encoding make my HTML safe?

It escapes the five characters that break markup, which handles the common cases. Attribute context, JavaScript context and URLs need their own escaping rules — do not rely on this alone for untrusted input.

Which entities are decoded?

Decimal and hex numeric entities plus the common named ones (amp, lt, gt, quot, apos, nbsp, copy, reg, trade, hellip, mdash, ndash, laquo, raquo). Unknown names are left untouched.

Why does &nbsp; sometimes break my layout?

It is a non-breaking space, not a normal one, so lines cannot wrap there and the character is not collapsed by HTML whitespace rules. Use it deliberately.
