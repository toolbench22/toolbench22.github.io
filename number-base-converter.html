Number Base Converter (Binary, Octal, Decimal, Hex)

Convert numbers between decimal, binary, octal and hexadecimal at once. Accepts 0x, 0b and 0o prefixes and handles negative values.

How to use the Number Base Converter

  1. Type a number — plain decimal, 0x for hex, 0b for binary, 0o for octal.
  2. All four representations appear at once with no extra clicks.
  3. Copy the base you need; negative numbers keep their sign.

Frequently asked questions

How do I read a hex color like ff8800?

Each pair of hex digits is one byte: ff = 255, 88 = 136, 00 = 0, giving rgb(255, 136, 0). Any base conversion tool shows you the decimal values.

Does it support floating point in other bases?

No, integers only. Fractional binary and hex need a different algorithm and are rarely needed by hand.

Why does a 32-bit hex value come out negative?

If the value was read from a signed integer field, the top bit is the sign. Mask it or reinterpret as unsigned in your code.
