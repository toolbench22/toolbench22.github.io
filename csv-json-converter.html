CSV to JSON and JSON to CSV Converter

Convert CSV to a JSON array of objects and JSON back to CSV. Handles quoted fields, embedded commas, escaped quotes and custom delimiters.

How to use the CSV to JSON

  1. Paste your CSV with a header row, or your JSON array of objects.
  2. Choose the direction and the delimiter: comma, semicolon or tab.
  3. Press Convert. Errors such as malformed quotes are reported instead of silently producing wrong data.

Frequently asked questions

How are commas inside values handled?

The parser is RFC 4180 aware: a field wrapped in double quotes may contain delimiters, escaped quotes ("") and line breaks, and stays one value.

What if my rows have different numbers of columns?

Missing values become empty strings, so the JSON stays rectangular and predictable instead of dropping keys.

Are numbers converted to real numbers?

No. Everything stays a string, which is deliberate — it prevents losing leading zeros in IDs and phone numbers. Cast in code where you need numeric types.
