Percentage Calculator

Five percentage calculations in one tool: X% of Y, what percent X is of Y, percent change, percent increase and percent decrease.

How to use the Percentage Calculator

  1. Pick the calculation you need from the dropdown; the two input labels change to match.
  2. Type both values — the result updates as you type.
  3. Percent change returns a negative number when the value went down, so the direction is never ambiguous.

Frequently asked questions

How is percent change calculated?

(new - old) / |old| x 100. The absolute value in the denominator means a drop from -100 to -50 also reads as +50%, which is what most people expect.

Why is dividing by zero refused?

Percent-of and percent-change have no meaning when the base is zero — the result would be infinite. The tool reports the problem instead of showing Infinity.

Does it round the result?

Results are trimmed to 12 significant digits to remove floating point noise such as 0.30000000000000004 while keeping real precision.
