Base64 Encoder & Decoder

Encode text to Base64 or decode Base64 back to text, with full UTF-8 support and an optional URL-safe alphabet. Runs entirely in your browser.

How to use the Base64 Encoder

  1. Type text in the left box and press Encode to get Base64 on the right.
  2. To go the other way, paste Base64 in the left box and press Decode.
  3. Tick "URL-safe alphabet" when the output goes into a filename, a query string or a JWT — that swaps +/ for -_ and drops padding.

Frequently asked questions

Does it handle emoji and non-Latin text?

Yes. The text is encoded to UTF-8 bytes first, then to Base64, so Chinese, Arabic and emoji all round-trip correctly.

Is Base64 encryption?

No. It is a reversible encoding with no key. Anyone can decode it in one second, so never use it to protect passwords or tokens.

Why do I get an error when decoding?

Invalid characters, missing padding or a URL-safe string decoded with the standard alphabet. Tick the URL-safe box if the string contains - or _.
