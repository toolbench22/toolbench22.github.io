Random Number Generator

Generate random integers or decimals in any range, up to 1000 at once, with an option to force unique values. Uses the browser crypto RNG.

How to use the Random Number Generator

  1. Set the minimum and maximum. Reversed values are swapped automatically.
  2. Choose how many numbers you need (1-1000) and how many decimal places.
  3. Tick "Unique only" for draws, lottery picks or test IDs where duplicates would be wrong.

Frequently asked questions

Is the randomness good enough for a draw?

Values come from crypto.getRandomValues, a cryptographically secure generator, so there is no predictable seed to game. The unique mode rejection-samples to avoid duplicates.

Why does unique mode complain?

You asked for more unique integers than the range can hold — a range of 1-5 only has five integers. Widen the range or lower the count.

Can I get the same list twice?

No. Each run draws fresh values; there is no seed input, which is the point for anything where predictability matters.
