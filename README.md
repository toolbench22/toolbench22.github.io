# ToolBench — 22 free browser-side developer tools

**Live site: https://toolbench22.github.io/**

Every tool runs entirely in your browser. Nothing you paste is uploaded, logged or stored — kill your network after the page loads and the tools keep working.

## Tools

| Category | Tools |
|---|---|
| Developer | JSON Formatter, Base64 Encoder/Decoder, URL Encoder, Timestamp Converter, UUID Generator, Color Converter, Regex Tester, HTML Entity Encoder |
| Text | Word Counter, Case Converter, Lorem Ipsum, Diff Checker, Slug Generator, Line Sorter, Markdown Previewer |
| Converters | Unit Converter (8 families), Number Base Converter, Text↔Binary |
| Data | CSV ⇄ JSON |
| Security | Password Generator, SHA-1/256/384/512 Hash Generator, JWT Decoder |

## Why

Most online utilities send your input to a server. That is fine for a URL slug and a terrible idea for a JWT, an API key or an unpublished draft. This site is static HTML/CSS/JS with no backend at all: the logic runs on your device using standard web APIs (`JSON.parse`, `TextEncoder`, `crypto.subtle`).

## Stack

- Static site, generated by a small Node script
- 22 tool pages + 6 policy pages
- Per-page JSON-LD (`WebApplication` + `FAQPage` + `BreadcrumbList`)
- `robots.txt`, `sitemap.xml`, `ads.txt`
- Unit-tested core logic, plus real-browser acceptance tests
