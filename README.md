# ToolBench — 33 free browser-side developer tools

**Live site: https://toolbench22.github.io/**

Every tool runs entirely in your browser. Nothing you paste is uploaded, logged or stored — kill your network after the page loads and the tools keep working.

## Tools

| Category | Tools |
|---|---|
| Developer | JSON Formatter, Base64 Encoder, URL Encoder, Timestamp Converter, UUID Generator, Color Converter, Regex Tester, HTML Entity Encoder, Base32 Encoder, Random Number Generator, CIDR Calculator, Unicode Inspector |
| Text | Word Counter, Case Converter, Lorem Ipsum Generator, Diff Checker, Slug Generator, Line Sorter, Markdown Previewer, Text Reverser |
| Converters | Unit Converter, Number Base Converter, Text to Binary, Morse Code Translator, Roman Numeral Converter |
| Data | CSV to JSON |
| Security | Password Generator, Hash Generator, JWT Decoder |
| Calculators | Percentage Calculator, Age Calculator, Date Difference Calculator, Aspect Ratio Calculator |

## Why

Most online utilities send your input to a server. That is fine for a URL slug and a terrible idea for a JWT, an API key or an unpublished draft. This site is static HTML/CSS/JS with no backend at all: the logic runs on your device using standard web APIs (`JSON.parse`, `TextEncoder`, `crypto.subtle`).

## Stack

- Static site generated by a small Node script (no framework, no build tooling beyond it)
- 33 tool pages + 6 policy pages
- Per-page JSON-LD (`WebApplication` + `FAQPage` + `BreadcrumbList`)
- `robots.txt`, `sitemap.xml`, `ads.txt`, IndexNow key for instant indexing
- Unit-tested core logic plus real-browser acceptance tests
